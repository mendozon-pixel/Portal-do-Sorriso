# 🦷 Portal do Sorriso - Site Institucional

Site institucional da clínica odontológica **Portal do Sorriso**, localizada em Pinheiros, São Paulo.

## 📋 Sobre o Projeto

Landing page de página única (one-page) para apresentar a clínica, seus serviços, diferenciais e facilitar o agendamento de consultas.

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura semântica
- **CSS3** — Estilização com variáveis CSS, Flexbox e Grid
- **JavaScript** (Vanilla) — Interatividade (menu, FAQ, formulário)
- **Google Fonts** — Fontes Montserrat e Playfair Display
